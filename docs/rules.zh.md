# AnySearch 开源赏金计划

报名截止：2026-10-31 23:59 UTC+8

奖池：人民币 10 万元，发完即止。

## 报名

报名链接：[点击报名](https://forms.gle/i3azg6dATzCvYeED6)

仅以活动页面表单作为正式报名渠道。聊天记录、Issue、邮件等不作为报名入口。

报名目的：报名用于登记开发者或开发者团队（下文统一称“开发者”）与目标项目的对应关系。报名不等同于奖励审核通过。

主办方将尽快邮件确认是否收到报名，并告知是否属于本活动受理范围及后续信息。

## 项目范围

1. 可选项目以官方项目清单为准，具体见项目列表 [Bounty Project List](../bounty-projects.md) 。

2. 同一目标仓库同时仅保留 1 个有效认领编号，认领有效期间仅对应开发者可提交有效 PR。认领失效后由下一顺位开发者递补，奖金发放给有效认领编号对应的、首个成功完成符合要求 Merge 的开发者。

3. 开发者可以通过活动报名表自荐符合条件的开源 AI Agent 项目。AnySearch 将对自荐项目进行评估，符合条件的项目将纳入下一期开源赏金计划项目清单。

## 奖金

1. 奖池总额人民币 10 万元，发完即止。

2. 奖池余额不足时，停止发放新的认领编号，已获得有效认领编号的开发者及任务不受影响。

3. 各目标项目的奖金金额由 AnySearch 在 [Bounty Project List](../bounty-projects.md) 中提前指定并公布，具体以活动发布时项目列表公布的奖金金额为准，活动发布后奖金金额即锁定，不再调整。

4. 活动周期内，同一自然人累计最多获得 3 次奖金（按已打款计）。

5. 所有奖金为税前金额；手续费、汇兑费用等由开发者承担。

## 参与资格

1. 遵守目标项目适用的开源许可证及相关项目规则，并提供合规收款信息。

2. 如实填写开发者本人与目标仓库的关系。

3. 须先完成官方报名，且合入仓库与报名登记的目标项目一致，变更目标项目须重新报名。

4. 奖金仅发放给对应认领编号的开发者。

5. AnySearch 员工及关联人员不得参加，不得邀请他人代领。

6. 主办方有权根据 GitHub 账号、代码提交、仓库贡献、收款信息等判断是否存在关联主体或作弊行为。

## 参与流程

1. 报名提交：开发者通过官方活动链接提交报名信息。报名信息用于建立开发者与目标项目之间的对应关系，并明确同一目标项目下的开发者报名顺序。

2. 报名确认：AnySearch 将尽快确认报名申请。符合条件的报名将通过邮件发送唯一认领编号，并锁定对应任务。多人报名同一目标项目时，按报名顺序进入候补队列，当前认领失效后由下一顺位递补。认领状态将通过邮件通知，并在官方活动页面展示。

3. PR 与合入：获得认领编号后，开发者自行向目标项目仓库提交 Pull Request，并推进 AnySearch 集成合入。开发者需在获得认领编号后 7 个自然日内提交有效 PR 并向 AnySearch 官方邮件反馈有效链接，否则视为自动放弃该认领资格。

4. 奖金申请：开发者将 AnySearch 成功合入（Merge）目标项目仓库后，需通过邮件提交合入证明材料。

5. 审核与打款：AnySearch 将审核项目范围、认领关系、PR 合入真实性、集成可用性及质量。审核通过并确认收款资料后，原则上 14 个工作日内发起付款。

以下情况认领编号失效，并由下一顺位开发者递补：

- 获得认领编号后 7 个自然日内未提交有效 PR； 

- 开发者主动放弃； 

- 提交内容明显不符合活动要求；

- 其他导致认领资格失效的情况。

## 什么样的合入可以获得奖励？

合格集成至少需满足：

1. 采用内置 API / MCP / Skill 或其他接入形式。
   （内置定义：代码合入主仓库、随发布包分发、或项目官方文档列为默认集成）
   
2. 开发者需根据项目官方要求，选择合适的 AnySearch 接入方式并完成最终 Merge。同时，在项目框架允许的范围内，尽可能集成 AnySearch 以下全部搜索能力：

   - 通用搜索能力（包括匿名搜索、并行搜索）

   - 垂直搜索能力

   - Extract 网页解析能力
   
3. 提交一份 Markdown（.md）格式的项目开发文档，便于后续维护。

> **说明：** 如目标项目 Maintainer 拒绝、关闭或长期未处理 PR，或因项目技术架构、维护状态等原因导致原接入方案无法继续，AnySearch 将结合实际情况判断是否保留认领资格、调整接入方案、延长处理时间或重新开放任务。如最终未形成符合要求的 Merge，则不产生奖金支付义务。
