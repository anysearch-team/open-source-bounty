# 常见问题 | AnySearch 开源赏金计划

> [English](faq.md) | [中文](faq.zh.md)

## 谁可以参与？

除 AnySearch 员工及关联人员外，任何开发者或开发者团队均可参与，并须遵守目标项目的许可证及相关规则。

## 可以自荐项目吗？

可以。AnySearch 将对自荐项目进行审慎评估，但自荐项目不纳入本期活动奖励范围；符合条件的项目可能纳入后续活动的目标接入项目清单。

## 哪些项目符合要求？

就本期活动而言，可获得奖励的项目以官方项目清单为准。

## 同一个项目可以多人认领吗？

同一仓库同时仅允许 **1 个有效 Claim ID**。多人报名按顺序进入候补队列，当前认领失效后依次递补。

## 可以先提交 PR 再报名吗？

不可以。须先报名并获得有效 **Claim ID**，再提交 PR。

## Claim ID 有效期多久？

获得 Claim ID 后，须在 **7 个自然日内提交有效 PR**，否则认领自动失效。

## 什么样的集成可以获得奖励？

集成须让用户能够在目标项目中**真实使用 AnySearch**，并成功合入官方仓库。

## 可以使用哪些接入方式？

可以采用内置 API、MCP、Skill 或其他接入方式，具体应符合目标项目的集成方式及项目规则。

## 奖金如何确定？

各目标项目的具体奖金金额由 AnySearch 在活动发布前确定并公布，以官方项目清单公布的金额为准。

## 什么时候可以收到奖金？

PR 成功合入并通过审核、收款资料确认后，原则上 **14 个工作日内发起付款**。
